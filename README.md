# Tic-Tac-Toe

A simple Tic-Tac-Toe desktop game built in Python using Tkinter.

## Features

- Choose to play as X or O
- Play against a computer opponent with random valid moves
- Win and tie detection
- Replay functionality
- Home, gameplay, and help pages

## Technologies

- Python
- Tkinter
- Random

## Running the Project

Run the Python file:

```bash
python TicTacToeTkinter.py
